# B 站发布介绍：演示步骤与逐段文案

建议成片 5–6 分钟，横屏 1920×1080，手机竖屏放中间，右侧放任务说明和关键结果。时间是剪辑建议；等待可以加速并标注倍速。先完整试跑，再录制。

## 选哪条路线

**现在优先录 B 路线：开发过程与预览版发布。** 当前证据是 APK 构建/离线测试通过，但手机授权页曾返回地区限制，真实 Plus 模型调用未验证。

**A 路线：实机功能展示。** 只有你本人在手机完成登录，并确认下列任务实测成功，才使用 A 路线对应镜头和口播。某项失败就展示真实失败或删去，不用成功字幕覆盖失败画面。

画面中的上游截图应标“上游项目截图”；代码与测试画面标“本分支改动 / 本地验证”；只有自己的手机完整跑通任务才标“本机实录”。本稿是录制计划，不是已经完成的实机验收记录。

## 开拍前准备

1. 电脑打开本仓库中文 README、Release、技术分析和测试报告；录屏使用浏览器与代码窗口，隐藏本地个人目录。
2. 手机安装 APK。开启必要的无障碍与悬浮窗；Termux 按原项目设置向导配置到 Ready。
3. 手机开勿扰，关闭通知预览。使用没有聊天、联系人、金融信息的干净演示界面。
4. 登录在录制前由本人完成；不要录密码、验证码、邮箱、完整授权网址或回调参数。展示设置时也隐藏账号信息。
5. 云模型会接收任务和必要的屏幕内容。画面与口播不要说成“完全离线”“所有数据不出手机”。
6. 若需要展示当前错误，仅保留错误码区域，并把网址参数全部遮挡。不要把地区限制剪成模型调用错误。
7. 口播中使用“社区二次开发 / 兼容修复版”。视频开头与简介保留上游项目链接，避免将整个应用称为个人从零原创。

## A 路线：实机通过后使用

总时长建议 5–6 分钟。开头先放 10–15 秒成功操作，再解释来源和修改。以下每个任务都应新建会话，保留执行步骤和最终结果；不要手动完成后称为 AI 自动完成。先录下完整等待，再在剪辑中标注加速。

### 演示 1：打开、读取和返回

将下面这句粘贴到 ClosePaw：

> 打开系统设置，读取首页前 3 个可见的设置分类，用一句话告诉我，再返回主屏幕。不要修改任何设置，不要进入账号或个人信息页面。

拍摄顺序：输入任务 → 开始 → 自动打开设置 → 屏幕读取与点击轨迹 → 返回主屏幕 → 展示回复。成功标准：确实打开设置，回复与屏幕对应，并返回主屏幕；没有修改设置。

口播：“先看一个短任务：打开设置、读取可见内容，然后返回桌面。右侧是我的指令，中间是手机实录。大家可以对照屏幕和结果，确认它完成了哪些步骤。”

### 演示 2：滑动与截图感知

在 ClosePaw 的感知设置中按实际界面选择截图或混合模式，新建会话后输入：

> 打开系统设置首页，向上滑动一次，描述滑动后屏幕上 3 个可见分类，再向下滑动一次并返回主屏幕。不要修改设置，不要打开个人信息页面。

成功标准：画面确实发生滑动，回复对应滑动后的内容；截图/混合模式是否实际发送图像，应从脱敏的请求摘要或感知设置核对。仅看到文字回答不能证明使用了视觉。不要为了证明截图而打开含个人内容的原始 trace。

口播：“第二个任务增加一次滑动，并使用我当前启用的感知模式。模型需要根据操作后的界面继续决定下一步。这里展示的是实际屏幕变化；如果要判断是否用了截图，还要核对感知配置和请求记录。”

### 演示 3：Termux 的真实文件结果

先展示 Termux 集成 Ready；新建会话输入：

> 使用 termux_shell，在默认工作目录中新建一个不重名的 demo 子目录。用 Python 生成 1 到 100 的平方数 CSV，列名为 number,square；保存为 squares.csv。读取该文件并返回数据行数、前 3 行、最后 1 行以及 SHA-256。只在新目录中操作，不覆盖已有文件，不控制 Android 界面。

成功标准：结果含 100 行数据；前三行应为 1,1 / 2,4 / 3,9，最后一行是 100,10000。手动打开 Termux，进入工具返回的**实际目录**，运行 `wc -l squares.csv`、`head -n 4 squares.csv`、`tail -n 1 squares.csv`、`sha256sum squares.csv` 核对。含表头时 `wc -l` 应为 101。SHA 值取决于换行等实际写入字节，不在视频中预填固定值。

口播：“第三个任务把 AI 的执行能力延伸到 Termux。它需要真的生成一个 CSV，再读取和校验，而不是只在聊天里描述一个文件。我会打开终端独立检查行数、内容和哈希，确认结果可以复现。”

### A 路线的连接口播

- 片头：“一句自然语言，能不能让手机自己完成一组操作？今天给大家看 ClosePaw 的社区兼容修复版。这一段是我这台手机上的实际录制，使用的是我账号当前可用的模型。”使用前必须确实有对应实录。
- 演示后解释：“ClosePaw 的手机自动化能力来自上游开源项目。我这次重点修复 ChatGPT OAuth、模型迁移和工具协议，完整修改已经放在 GitHub。”
- 登录部分：“登录由我本人在官方页面完成。视频不展示凭证。订阅入口不需要填写 API Key，但模型权限和额度仍以账号为准。”
- 收尾：“本机这三项任务的结果已经展示。它仍是社区预览版，不代表所有手机和账号都能复现；具体系统、模型和版本我写在简介里。”简介填写你的真实设备与模型，未测试项目直接写“未验证”。
